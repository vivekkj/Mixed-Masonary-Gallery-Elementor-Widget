# Elementor Mixed Masonry Gallery

A lightweight custom Elementor widget that allows you to create beautiful masonry galleries containing both **images and videos** in the same gallery.

Unlike Elementor's native Gallery widget, this plugin supports:

* Images and videos in the same masonry layout
* YouTube videos
* Vimeo videos
* Self-hosted MP4/WebM/Ogg videos
* Custom lightbox popup
* Previous / Next navigation
* Mobile swipe navigation
* Responsive column controls
* Elementor-native editing experience

---

## Features

### Mixed Media Gallery

Display images and videos together in a masonry grid.

### Responsive Layout Controls

Configure different column counts for:

* Desktop
* Tablet
* Mobile

Directly from Elementor's responsive controls.

### Custom Lightbox

Includes a built-in lightbox with:

* Image viewing
* Video playback
* Previous / Next navigation
* Keyboard navigation
* Mobile swipe support
* Item counter

### Supported Media

#### Images

* JPG
* JPEG
* PNG
* WEBP
* GIF

#### Videos

* YouTube
* Vimeo
* MP4
* WebM
* Ogg

## Installation

### Manual Installation

1. Download the plugin ZIP.

2. Navigate to:

   WordPress Admin → Plugins → Add New → Upload Plugin

3. Upload the ZIP file.

4. Activate the plugin.

5. Open Elementor.

6. Search for:

   Mixed Masonry Gallery

7. Drag the widget into your page.

---

## Usage

### Adding Images

1. Add a Gallery Item.
2. Select:

   * Item Type → Image
3. Upload or select an image.
4. Add an optional title.

### Adding Videos

1. Add a Gallery Item.
2. Select:

   * Item Type → Video
3. Upload a thumbnail image.
4. Paste:

   * YouTube URL
   * Vimeo URL
   * MP4 URL

The thumbnail will appear in the gallery and the video will open inside the lightbox.

## Lightbox Controls

### Mouse

* Click image/video → Open lightbox
* Click outside → Close
* Previous arrow → Previous item
* Next arrow → Next item

### Keyboard

* Left Arrow → Previous
* Right Arrow → Next
* ESC → Close

### Mobile

* Swipe Left → Next item
* Swipe Right → Previous item
